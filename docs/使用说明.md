# WellSteam v1.0 使用说明

**严禁商用，仅限非商业科研、教学和个人学习。** [完整许可](../LICENSE.txt)

## 安装

适用 Windows 10/11 64 位。下载 [Release 安装包](https://github.com/13PG/WellSteam/releases/latest)，运行安装器，然后通过快捷方式打开软件。无需安装 Python 或 CUDA，无需运行构建脚本。

## 输入

| 参数 | 单位 |
|---|---|
| 井口压力 | MPa |
| 注汽质量流量 | kg/s |
| 井口干度 | % |
| 计算井深 | m |
| 隔热层导热系数 | W/(m·K) |
| 地温梯度 | ℃/m |
| 地层热扩散率 | m²/s |
| 井底压力边界 | MPa |
| 井斜角 | ° |

注汽质量流量不可直接填写为体积流量、线速度或仪器转速。同一质量口径的 t/h 可除以 3.6 换算为 kg/s。

## 计算和显示

选择 PI-GNN、PI-DeepONet 或 EP-PI-DeepONet，再点击“运行预测”。同页可开启三模型对比。默认采用各模型三个正式种子的预测均值。

输出间隔填写 1–1000 m，支持 5 m、10 m 等设置；软件拒绝空值、零和负值。原生计算网格约 30 m，较细输出通过线性插值获得。

场图支持预设配色、自定义低/中/高值颜色和色标反转。四项输出分别为温度 ℃、压力 MPa、干度 %、单位井长热损失 W/m。场图横向不代表真实径向位置。

## 记录与导出

新安装不包含计算历史，点击运行预测后才保存记录。可导出 CSV、JSON 和 PNG，并可在计算记录页清空历史。

数据默认保存在程序附近的 data 和 exports 目录；目录不可写时保存到当前用户的 LocalAppData/WellSteam。通过“文件 → 打开导出文件夹”可定位实际导出位置。

## 故障定位

无法启动时查看 data/errors.log 或 data/desktop.log。Windows 安装包不支持 macOS；本公开仓库不提供源码运行或本地构建支持。
